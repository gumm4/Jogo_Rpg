# Jogo_Rpg
Este é um projeto, onde criei um jogo de aventura em Python, utilizando o próprio terminal da IDE. Neste jogo foquei em fazer um sistema me concentrei em fazer um sistema para contar os pontos ganhos pelo jogador e dar um título baseado na quantidade de pontos alcançadas.

Usei estruturas de while para rodar o jogo enquanto o sistema estivesse sendo rodado e para fazer o sistema de vida do protagonista e de vida com o chefe.

Funções para criar o sistema de soma para pontos, a quantidade de pontos adquiridos para cada objetivo concluído e contagem de objetivos para somar com os pontos totais
